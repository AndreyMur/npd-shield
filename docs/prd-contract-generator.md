# PRD: Safe Contract Generator

**Дата**: 2026-08-31
**Статус**: Draft

## Цель

Позволить ИП на НПД создавать юридически выверенные договоры за 2 минуты вместо 2 часов у юриста, с автоматическими «защитными формулировками» которые доказывают гражданско-правовой характер отношений и снижают риск переквалификации.

## Пользовательские сценарии

- Пользователь выбирает шаблон договора -> Получает готовый документ с адаптацией под его ОКВЭД
- Пользователь заполняет поля формы -> Автоматически подставляются реквизиты из профиля
- Пользователь нажимает «Создать договор» -> Получает PDF-файл с защитными формулировками
- Пользователь отправляет договор заказчику -> Договор доступен для шаринга через стандартные приложения

## В скоупе

- Библиотека из 20+ шаблонов договоров (юридически выверенных)
- Автоматическая адаптация шаблонов под ОКВЭД (49.41 для логистики, 62.01/62.02 для IT)
- Автозаполнение реквизитов ИП из профиля (ИНН, ОГРНИП, адрес, расчётный счёт)
- Специфичные поля для каждой сферы:
  - **Логистика:** маршрут, вес груза, характеристики ТС, срок доставки, стоимость перевозки
  - **IT:** описание результата, техтребования, этапы сдачи, стоимость работ
- Генерация PDF с кириллицей и корректным форматированием
- Сохранение черновиков и архив подписанных договоров
- «Защитные формулировки» в каждом шаблоне (доказательства ГПХ-характера)

## Не в скоупе

- Электронная подпись документов (Фаза 3)
- Юридическая экспертиза каждого договора (отдельная фича Risk Shield)
- Интеграция с 1С для автоматической выгрузки договоров
- Мультиязычность шаблонов (только русский язык)
- Шаблоны для иностранных контрагентов

## Технические ограничения

- Генерация PDF происходит локально без серверной обработки
- Шаблоны хранятся в Assets приложения
- Максимальный размер шаблона: 50 КБ
- Поддержка кириллицы через встроенные шрифты (Roboto)

## Критерии готовности

- [ ] Библиотека содержит минимум 20 шаблонов (10 для IT, 10 для логистики)
- [ ] Время создания договора: < 2 минут от выбора шаблона до готового PDF
- [ ] 100% шаблонов содержат защитные формулировки
- [ ] PDF корректно отображается в Adobe Reader, Apple Preview, Chrome
- [ ] Автозаполнение реквизитов работает при наличии данных в профиле
- [ ] Сохранение черновиков и восстановление сессии
- [ ] Accessibility: все поля формы доступны для скринридеров

## Функциональные требования

### Библиотека шаблонов

- Категории: «Логистика», «IT-услуги», «Универсальные»
- Карточка шаблона: название, описание, пример заполнения
- Поиск и фильтрация по типу деятельности
- Пометка «Рекомендовано» для наиболее безопасных шаблонов

### Конструктор договора

- Пошаговый мастер заполнения (3-5 шагов)
- Обязательные и опциональные поля с валидацией
- Предпросмотр документа в реальном времени
- Подсказки для каждого поля (что вводить, зачем нужно)

### Защитные формулировки

- Автоматическая вставка стандартных формулировок, доказывающих ГПХ-характер:
  - «Исполнитель самостоятельно определяет порядок выполнения работ»
  - «Сроки выполнения работ определяет Исполнитель»
  - «Результат работ передаётся по акту приёма-передачи»
- Маркировка защитных формулировок визуально (значок щита)

### Генерация PDF

- Формат: A4, поля 20 мм
- Шрифт: Roboto Regular 12pt, заголовки 14pt bold
- Нумерация страниц
- Подписи сторон (поля для распечатки и подписи)

### Управление договорами

- Статусы: Черновик → Подписан → Архив
- Редактирование черновиков
- Дублирование существующего договора
- Поиск по названию, контрагенту, дате

## Нефункциональные требования

- **Производительность:** генерация PDF за < 2 секунд
- **Безопасность:** шаблоны не содержат вредоносного кода, валидация ввода
- **Доступность:** доступность форм для скринридеров, клавиатурная навигация
- **Надёжность:** автосохранение черновика каждые 30 секунд

## Дизайн и UX

- Пошаговый мастер с индикатором прогресса
- Карточки шаблонов с превью и описанием
- Цветовая маркировка: IT — синий, Логистика — оранжевый
- Floating Action Button для быстрого создания нового договора
- Bottom sheet для предпросмотра PDF перед сохранением

## Критерии успеха (KPI)

- **Time to contract:** < 2 минут от выбора шаблона до готового PDF
- **Доля договоров с защитными формулировками:** 100%
- **Retention rate:** > 60% пользователей создают минимум 2 договора в месяц
- **NPS:** > 50 для модуля генератора

## Ограничения и риски

- **Риск:** шаблоны могут устаревать с изменением законодательства -> **Митигация:** обновление шаблонов через App Store, уведомление пользователей
- **Риск:** пользователь может неправильно заполнить поля -> **Митигация:** валидация, подсказки, примеры заполнения
- **Ограничение:** шаблоны не заменяют юридическую консультацию -> **Митигация:** дисклеймер в приложении

## Границы объёма работ

**Входит:**
- 20+ шаблонов договоров (IT и логистика)
- Пошлаговый мастер заполнения
- Генерация PDF с кириллицей
- Сохранение и архив договоров
- Защитные формулировки

**Исключено:**
- Электронная подпись
- Юридическая экспертиза (Risk Shield)
- Интеграция с 1С
- Мультиязычность
- Шаблоны для иностранных контрагентов
