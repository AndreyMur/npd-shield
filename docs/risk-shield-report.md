# Отчёт по модулю Risk Shield (Фаза 12)

## Дата: 2026-09-12
## Ветка: feature-phase-12

## Назначение

Индекс безопасности и визуализация рисков: пользователь видит индекс (0–100%)
с цветовой шкалой и детальный разбор найденных рисков с копируемыми
безопасными альтернативами.

## Что реализовано

| Задача | Реализация |
|--------|------------|
| Расчёт индекса безопасности | `SafetyIndexCalculator` (`lib/domain/risk/safety_index.dart`), подключён в `RiskAnalyzerUseCase` |
| Визуализация индекса | `SafetyIndexGauge` (`lib/presentation/risk/safety_index_gauge.dart`) — круговая диаграмма `fl_chart`, процент и цветовая шкала |
| Список рисков | `_RiskList` и `_RiskCard` (`lib/presentation/risk/risk_shield_screen.dart`): цветная полоса слева, фильтр по уровню, раскрывающиеся секции |
| Копирование альтернативы | Кнопка «Скопировать формулировку» → `Clipboard.setData` + подтверждение |
| Тесты | `test/safety_index_test.dart`, обновлённый `test/risk_shield_screen_test.dart` |

## Формула индекса

`index = 100 × (1 − сработавшие / всего) − Σ штрафов`, результат ограничен 0–100:

* широта — доля уникальных сработавших маркеров от всей базы;
* штрафы — критический 35, средний 12, низкий 3;
* повторные срабатывания одного маркера штрафуют один раз;
* нет рисков или пустая база → 100%.

Цветовые зоны: зелёный ≥ 80%, жёлтый 50–79%, красный < 50%.

## Доступность

* Цвет не единственный способ передачи уровня: у индекса есть текстовая метка
  зоны, у риска — текстовая метка уровня.
* Круговая диаграмма обёрнута в `Semantics` с меткой «Индекс безопасности: N
  процентов. Уровень.», диаграмма исключена из дерева семантики.
* Карточка риска помечена как кнопка с состоянием «развёрнуто/свёрнуто».
