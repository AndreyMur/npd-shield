# Отчёт по модулю Risk Shield (Фаза 13)

## Дата: 2026-09-12
## Ветка: feature-phase-13

## Назначение

История проверок: сохранение результатов каждой проверки договора и доступ к
ним для повторного просмотра и удаления. История персистентна между сессиями.

## Что реализовано

| Задача | Реализация |
|--------|------------|
| Сохранение результатов | `RiskShieldScreen` сохраняет `RiskReport` (договор, дата, индекс, риски) через `RiskReportRepository`; добавлен геттер `RiskReport.riskCount` |
| Экран истории | `RiskHistoryScreen` (`lib/presentation/risk/risk_history_screen.dart`) — список проверок с датой, индексом и числом рисков |
| Повторный доступ | `RiskReportDetailScreen` открывает сохранённый отчёт; общий `RiskReportView` переиспользуется экраном анализа и экраном истории |
| Удаление | Кнопка удаления в карточке с подтверждением → `RiskReportRepository.delete` и перезагрузка списка |
| Тесты | `test/risk_history_screen_test.dart`, дополнен `test/risk_report_repository_test.dart`, обновлён `test/risk_shield_screen_test.dart` |

## Архитектура

* `RiskReportRepository` (`getAll` / `getById` / `delete` / `clear`) — источник
  истории; `IsarRiskReportRepository` сортирует отчёты от новых к старым и
  шифрует чувствительные поля (имя файла, найденные фрагменты).
* Представление результата вынесено в переиспользуемый `RiskReportView`
  (`lib/presentation/risk/risk_report_view.dart`): экран анализа добавляет
  действие «Проверить другой договор», экран истории — ничего.
* Вход в историю — кнопка `Icons.history` в AppBar экрана Risk Shield (доступна,
  когда передан репозиторий отчётов).
* Дата форматируется как `дд.мм.гггг чч:мм` без зависимости `intl`, чтобы не
  зависеть от локали устройства в тестах.

## Доступность

* Уровень индекса передаётся не только цветом: рядом с цветным маркером выводится
  текстовая метка зоны («Высокая безопасность» / «Средний риск» / «Высокий риск»).
* Кнопка истории имеет подсказку `tooltip`, кнопка удаления — `tooltip`.
* Карточки риска сохраняют семантику «развёрнуто/свёрнуто».
