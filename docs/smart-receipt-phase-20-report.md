# Отчёт по модулю Smart Receipt (Фаза 20)

## Дата: 2026-09-14
## Ветка: feature-phase-20

## Назначение

Финализация модуля документов: автоматическая привязка документов к
транзакциям дашборда с визуальной индикацией, переход к документу из карточки
транзакции, экспорт всех типов документов (чек, акт, договор) в PDF и шаринг,
дисклеймер об отсутствии юридической силы без ЭЦП и сквозной smoke-тест.

## Что реализовано

| Задача | Реализация |
|--------|------------|
| Автоматическое сопоставление документов с транзакциями | Домен `lib/domain/documents/document_transaction_matcher.dart`: явная привязка по `transactionId` и эвристика «сумма + дата + контрагент» (ИНН, при отсутствии — наименование). Сервис `DocumentTransactionLinker` (`lib/domain/documents/document_transaction_linker.dart`) фиксирует найденные привязки в архиве |
| Визуальная индикация (значок документа) | `TransactionDocumentsCard` (`lib/presentation/dashboard/transaction_documents_card.dart`): список последних транзакций под сводкой дашборда, рядом с транзакцией — значок документа со счётчиком при нескольких документах. Дашборд получает `DocumentRepository` из `HomeShell` |
| Переход к документу из карточки транзакции | Нажатие на транзакцию с документами открывает Bottom sheet деталей; при нескольких документах сначала показывается выбор документа. Переиспользован `showDocumentDetailsSheet` |
| Экспорт всех типов документов в PDF | `DocumentPdfService` (`lib/data/pdf/document_pdf_service.dart`) теперь верстает и договоры: текст договора хранится в новом поле `Document.content` (шифруется AES-256) и собирается `ContractPdfService`. Договоры сохраняются в архив из `ContractWizardScreen` (поле `documentRepository`, передаётся из библиотеки и архива договоров) |
| Дисклеймер об ЭЦП | Единый текст `kNoLegalForceDisclaimer` (`lib/domain/documents/legal_disclaimer.dart`): баннер в архиве документов, строка в Bottom sheet деталей и колонтитулы PDF чека, акта и договора |
| Smoke-тест | `test/document_transaction_smoke_test.dart`: сделка → чек → акт → deep link → архив → поиск → привязка к транзакции |

## Рабочий путь

1. Пользователь завершает сделку в договоре — формируется чек, сохраняется в
   архив и (при включённой опции) записывается транзакция дохода.
2. На дашборде в списке транзакций у расчёта появляется значок документа.
   Если документ был создан без явной привязки, он сопоставляется по сумме,
   дате и контрагенту и привязка фиксируется автоматически.
3. Нажатие на транзакцию открывает карточку документа; при нескольких
   документах — выбор из списка.
4. В архиве документов доступны поиск, фильтры и экспорт: чек, акт и договор
   генерируются в PDF локально и отправляются через системное меню «Поделиться».

## Критерии готовности PRD

| Критерий | Проверка |
|----------|----------|
| Чек генерируется автоматически при завершении сделки | `receipt_smoke_test`, `deal_completion_screen_test` |
| Время формирования чека < 10 секунд | `receipt_pdf_service_test` (замер времени генерации) |
| Акт корректно заполняется из данных договора | `act_generator_test`, `act_smoke_test` |
| Deep link на «Мой налог» передаёт данные | `my_tax_deep_link_test`, `my_tax_deep_link_screen_test`, `document_transaction_smoke_test` |
| Архив доступен при 1000+ документах | `document_archive_test` (выборка 1000 документов) |
| Поиск < 500 мс на 1000 документах | `document_archive_test` |
| Accessibility | `document_archive_screen_test`, `dashboard_transaction_documents_test` |
| Привязка документов к транзакциям | `document_transaction_matcher_test`, `dashboard_transaction_documents_test`, `document_transaction_smoke_test` |
| Экспорт всех типов документов | `document_pdf_service_test`, `document_transaction_smoke_test` |
| Дисклеймер об ЭЦП | `document_transaction_smoke_test`, `document_archive_screen_test` |

## Ручная проверка на реальном устройстве

Автоматизированные тесты покрывают весь путь и критерии, проверяемые без
устройства. Для полного подтверждения PRD требуется ручной прогон на
мобильном устройстве:

1. Завершить сделку и убедиться, что чек появился в архиве за < 10 секунд.
2. Открыть deep link на «Мой налог» и проверить предзаполнение данных, а при
   отсутствии приложения — копирование в буфер и инструкцию.
3. Проверить системный шаринг PDF (чек, акт, договор) и сохранение в документы.
4. Открыть дашборд и перейти к документу из карточки транзакции.
5. Проверить скринридером список транзакций, архив, фильтры и Bottom sheet.
