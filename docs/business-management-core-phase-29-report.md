# Отчёт по модулю Business Management Core (Фаза 29)

## Дата: 2026-09-16
## Ветка: feature-phase-29

## Назначение

UI-фаза операций (Модуль 1): пользователь вручную ведёт доходы и расходы,
список фильтруется по типу, сфере, периоду и контрагенту и ищет по тексту,
итоги за период пересчитываются при изменениях, а дашборд показывает доход,
расход и прибыль.

## Что реализовано

| Задача | Реализация |
|--------|------------|
| Экран «Операции» | `OperationsScreen` (`lib/presentation/operations/operations_screen.dart`): список операций, сортировка по дате, карточка итогов за период (доход, расход, прибыль), фильтры по типу и сфере (чипы), периоду (всё время / месяц / год / свой диапазон) и контрагенту (выпадающий список), поиск по контрагенту, ИНН, категории и комментарию, пустые состояния «Операций пока нет» и «Ничего не найдено» |
| Форма операции | `TransactionFormScreen` (`lib/presentation/operations/transaction_form_screen.dart`): тип (доход/расход), сумма с валидацией > 0, дата в формате ДД.ММ.ГГГГ (с выбором через календарь), сфера, категория, контрагент, ИНН и комментарий; создание и редактирование с сохранением `id` |
| Удаление с подтверждением и отменой | Диалог подтверждения в `OperationsScreen`; после удаления — снекбар «Отменить», возвращающий операцию через `repository.add` |
| Дашборд | `DashboardScreen`: карточка «Прибыль» (доход, расход и прибыль за месяц, прибыль за год), расходы и прибыль в карточках сфер, корректное пустое состояние с кнопкой «Добавить операцию»; налог и лимит по-прежнему считаются только по доходам |
| Навигация | `HomeShell`: раздел «Операции»; на широких экранах — боковая `NavigationRail`, на узких — нижняя `NavigationBar` |

## Рабочий путь

1. Пользователь открывает раздел «Операции» и видит список с итогами за период.
2. Фильтры (тип, сфера, период, контрагент) и поиск сужают список; итоги
   пересчитываются по выбранным периоду и сфере.
3. Кнопка «Операция» открывает форму; после сохранения список и итоги
   обновляются.
4. Нажатие на карточку открывает форму редактирования, кнопка удаления
   запрашивает подтверждение, а затем предлагает отмену в снекбаре.
5. Дашборд показывает прибыль и расходы по сферам; при отсутствии операций
   выводится пустое состояние.
