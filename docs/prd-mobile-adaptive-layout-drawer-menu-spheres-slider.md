# PRD: Адаптивная верстка для телефона — меню-drawer и горизонтальный слайдер сфер

**Дата**: 2026-09-18
**Статус**: Draft

## Цель

Сделать мобильную версию приложения удобной на телефоне: заменить перегруженную нижнюю панель навигации на компактное выпадающее (боковое) меню со всеми разделами, а фильтр сфер деятельности на дашборде — на горизонтально прокручиваемый список. Пользователь быстрее находит нужный раздел и не теряет элементы управления на узком экране.

## Обзор продукта

Своё дело — Flutter-приложение для ИП на НПД. Навигационная оболочка (`HomeShell`) содержит 11 разделов: Дашборд, Операции, Клиенты, Счета, Шаблоны, Договоры, Документы, Проверка, Уведомления, Отчёты, Настройки. Сейчас на узких экранах используется нижняя панель `NavigationBar` со всеми 11 пунктами, а фильтр сфер на дашборде — `SegmentedButton` («Все / IT / Логистика»). Оба элемента плохо работают на телефоне: нижняя панель переполнена, фильтр не помещается.

## Цели и бизнес-задачи

- Устранить переполнение навигации на телефоне, чтобы все 11 разделов оставались доступными.
- Повысить скорость перехода между разделами на мобильных устройствах.
- Обеспечить читаемость фильтра сфер и его полную доступность на узких экранах.
- Не ухудшить десктопный опыт: текущая боковая навигация `NavigationRail` сохраняется.

## Пользовательские сценарии

- Пользователь открывает приложение на телефоне -> видит текущий экран без нижней панели навигации, с иконкой меню в шапке.
- Пользователь нажимает иконку меню -> открывается боковая панель со списком всех разделов (иконка + текст уменьшенным шрифтом).
- Пользователь выбирает раздел в меню -> панель закрывается, открывается выбранный экран.
- Пользователь открывает «Уведомления» через меню -> видит счётчик непрочитанных рядом с пунктом.
- Пользователь на дашборде свайпает список сфер по горизонтали -> выбирает «Все», «IT» или «Логистика»; дашборд пересчитывается под выбранную сферу.
- Пользователь нажимает системную кнопку «Назад» при открытом меню -> меню закрывается, приложение не закрывается.

## В скоупе

- Отключение нижней панели `NavigationBar` на телефоне (ширина < 900 px).
- Боковая панель (drawer) по иконке-гамбургеру со всеми 11 разделами: иконка + текст, уменьшенный шрифт.
- Индикация активного раздела в меню.
- Счётчик непрочитанных уведомлений в меню.
- Точка входа в меню (гамбургер) на всех экранах разделов.
- Закрытие меню после выбора раздела и по системной кнопке «Назад».
- Фильтр сфер на дашборде в виде горизонтально прокручиваемого списка (Все / IT / Логистика).
- Сохранение текущего поведения на широких экранах (>= 900 px) — `NavigationRail`.

## Не в скоупе

- Изменение десктопной боковой навигации и её внешнего вида.
- Изменение набора, порядка и названий разделов.
- Изменение логики фильтрации данных по сферам (только представление).
- Планшетный промежуточный layout с отдельным breakpoint.
- Изменение экранов, не относящихся к навигации и фильтру сфер.
- Анимации переходов и новые визуальные эффекты сверх существующих токенов.

## Функциональные требования

1. При ширине экрана < 900 px нижняя панель навигации не отображается.
2. На всех экранах разделов на телефоне доступна точка входа в основное меню (гамбургер).
3. Меню содержит все 11 разделов в текущем порядке с иконками и подписями.
4. Шрифт подписей в меню меньше, чем у подписей прежней нижней панели.
5. Активный раздел визуально выделен в меню.
6. У пункта «Уведомления» отображается счётчик непрочитанных при значении > 0.
7. Выбор раздела закрывает меню и открывает соответствующий экран; состояние экрана (скролл, вкладки) сохраняется, как и раньше.
8. Системная кнопка «Назад» при открытом меню закрывает только меню.
9. Фильтр сфер на дашборде — горизонтально прокручиваемый список; все три значения доступны свайпом.
10. Выбор сферы в слайдере пересчитывает дашборд так же, как текущий `SegmentedButton`.
11. При ширине >= 900 px поведение и внешний вид навигации не меняются.

## Нефункциональные требования

- Плавность: открытие меню и горизонтальный скролл сфер без просадок ниже 60 FPS на устройствах среднего класса.
- Доступность: пункты меню и слайдер доступны скринридерам, размер интерактивной области не меньше 48×48 dp.
- Локализация: подписи разделов и сфер остаются на русском.
- Офлайн: изменения не добавляют сетевых зависимостей.
- Тема: меню и слайдер корректно работают в светлой и тёмной темах через существующие токены.

## Дизайн и UX

- Меню: боковая выдвижная панель, сверху — название приложения/профиль, ниже — вертикальный список пунктов «иконка + текст».
- Типографика меню: уменьшенный размер относительно `bodyLarge`, единый для всех пунктов.
- Иконки: текущее семейство Material Symbols, контурная для неактивного и заполненная для активного пункта (как сейчас в навигации).
- Слайдер сфер: горизонтальный ряд компактных чипов с иконкой и подписью; активный чип выделен акцентным цветом, неактивные — нейтральные; при нехватке ширины ряд прокручивается.
- Точка входа в меню — иконка-гамбургер в шапке экрана; при прокрутке контента поведение шапки не меняется.

## Технические ограничения

- Breakpoint остаётся прежним: < 900 px — телефон, >= 900 px — широкий экран (`HomeShell._wideBreakpoint`).
- Навигационная оболочка (`HomeShell`) хранит выбранный индекс и строит `IndexedStack`; переключение разделов должно идти через тот же механизм.
- Каждый экран раздела имеет собственный `Scaffold` и `AppBar`, поэтому точка входа в меню должна быть доступна из любого экрана, а не только из оболочки.
- Счётчик непрочитанных уведомлений (`_unreadCount`) и индекс «Уведомления» (`_notificationsIndex = 8`) должны сохранить текущую логику.
- Фильтр сфер использует enum `DashboardFilter { all, it, logistics }`; состав значений фиксирован.
- В приложении 11 разделов — нижняя панель Material не рассчитана на такое количество, поэтому она полностью убирается на телефоне.

## Критерии готовности

- [ ] На ширине < 900 px нижняя панель `NavigationBar` не отображается ни на одном экране.
- [ ] На телефоне доступна иконка открытия меню на всех 11 экранах разделов.
- [ ] В меню отображаются все 11 разделов в текущем порядке с иконкой и текстом.
- [ ] Шрифт подписей меню визуально меньше шрифта подписей прежней нижней панели.
- [ ] Активный раздел выделен в меню иконкой/стилем.
- [ ] При непрочитанных уведомлениях > 0 счётчик виден у пункта «Уведомления» в меню.
- [ ] Выбор раздела закрывает меню и открывает нужный экран; состояние экранов сохраняется.
- [ ] Системная кнопка «Назад» при открытом меню закрывает меню, не закрывая приложение.
- [ ] Фильтр сфер на дашборде прокручивается по горизонтали, доступны все значения «Все», «IT», «Логистика».
- [ ] Выбор сферы меняет данные дашборда идентично прежнему поведению.
- [ ] На ширине >= 900 px `NavigationRail` отображается без изменений.
- [ ] Меню и слайдер корректны в светлой и тёмной темах.
- [ ] Существующие тесты навигации и дашборда проходят; при необходимости обновлены.

## Критерии успеха

- Все 11 разделов доступны с телефона без обрезания и переполнения.
- Среднее время перехода в раздел с телефона не выросло относительно текущего.
- Нет визуальных дефектов переполнения (`overflow`) на экранах 320–899 px.
- Доля ошибок/крашей, связанных с навигацией, не растёт.

## Ограничения и риски

- Ограничение: экраны владеют своими `AppBar`, из-за чего иконка меню должна дублироваться по экранам — риск рассинхронизации поведения.
- Риск: уменьшение шрифта меню может снизить читаемость — проверяем на минимальной ширине 320 px и в системном крупном шрифте.
- Риск: удаление нижней панели меняет привычный паттерн; нужен очевидный визуальный акцент на гамбургере.
- Риск: горизонтальный слайдер сфер может скрывать крайние значения — нужен явный признак прокручиваемости (частично видимый следующий чип).
