# Отчёт по модулю Smart Receipt (Фаза 19)

## Дата: 2026-09-14
## Ветка: feature-phase-19

## Назначение

Единый архив всех документов приложения (чеки, акты, договоры) с группировкой
по контрагентам, сортировкой, фильтрацией и быстрым поиском с автодополнением.
Из карточки документа открывается Bottom sheet с деталями и действиями
«Отправить», «Скачать PDF» и «Удалить».

## Что реализовано

| Задача | Реализация |
|--------|------------|
| Экран архива со списком документов | `DocumentArchiveScreen` (`lib/presentation/documents/document_archive_screen.dart`): список всех документов через `DocumentRepository.getAll()`, иконки по типу (`DocumentCard`), группировка по контрагентам с аватаром-инициалом и счётчиком документов, переключатель группировки в AppBar |
| Сортировка и фильтрация | Домен `lib/domain/documents/document_archive.dart`: `DocumentSort` (дата/сумма/тип, возр./убыв.) и `DocumentArchiveFilter` (тип + статус). В интерфейсе — чипы фильтра по типу и статусу, меню сортировки в AppBar |
| Поиск с автодополнением | `RawAutocomplete` с подсказками из `documentSearchSuggestions` (контрагенты, суммы, даты). Поиск по контрагенту, ИНН, услуге, номеру договора, типу, статусу, сумме и дате (`matchesDocumentQuery`) |
| Карточка документа (Bottom sheet) | `DocumentDetailsSheet` (`lib/presentation/documents/document_details_sheet.dart`): детали документа (контрагент, ИНН, дата, номер договора, услуга, результат и подписи для акта), кнопки «Отправить» (шаринг PDF), «Скачать PDF» (сохранение в документы) и «Удалить» (с подтверждением) |
| Экспорт PDF из архива | `DocumentPdfService` (`lib/data/pdf/document_pdf_service.dart`): по типу документа восстанавливает `Receipt`/`Act` из записи архива и генерирует PDF встроенными сервисами. Экспорт договоров — задача фазы 20 |
| Навигация | Новая вкладка «Документы» в `HomeShell` (`lib/presentation/home/home_shell.dart`) |

## Рабочий путь

1. Пользователь открывает вкладку «Документы» и видит все документы, сгруппированные
   по контрагентам.
2. Вводит запрос в строку поиска — список фильтруется, появляются подсказки
   (контрагенты, суммы, даты); выбирает подсказку или продолжает ввод.
3. Уточняет выборку чипами типа/статуса и меняет сортировку (дата, сумма, тип).
4. Нажимает на карточку — открывается Bottom sheet с деталями.
5. По кнопке «Отправить» PDF уходит в системное меню «Поделиться», по кнопке
   «Скачать PDF» файл сохраняется в документы, по кнопке «Удалить» документ
   удаляется после подтверждения.
