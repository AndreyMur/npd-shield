# Отчёт по модулю Business Management Core (Фаза 27)

## Дата: 2026-09-16
## Ветка: feature-phase-27

## Назначение

UI-фаза владения данными: первый запуск ведёт пользователя через онбординг,
даёт выбрать режим старта («с нуля» или «демо») и заполнить профиль ИП, а также
позволяет загрузить демо-данные и полностью очистить данные с подтверждением.
После очистки приложение возвращается к онбордингу — к состоянию «как после
установки».

## Что реализовано

| Задача | Реализация |
|--------|------------|
| Экран онбординга | `OnboardingScreen` (`lib/presentation/onboarding/onboarding_screen.dart`): три шага — выбор сфер деятельности, заполнение профиля ИП, выбор режима старта; прогресс, кнопки «Назад»/«Далее»/«Начать работу», валидация форматов ИНН/ОГРНИП/счёта/БИК |
| Сферы деятельности | `ActivitySpheresService` (`lib/data/services/activity_spheres_service.dart`): абстракция + `SharedPrefsActivitySpheresService`, хранит выбор в `SharedPreferences`; в `TransactionSphere` добавлено человекочитаемое `label` |
| Загрузка демо-данных | `showDemoDataConfirmation` (`lib/presentation/settings/data_management_dialogs.dart`) предупреждает о перезаписи профиля и добавлении демо; используется в онбординге и настройках |
| Полная очистка данных | `showDataResetConfirmation` — необратимое подтверждение с выделенной цветом ошибки кнопкой; `DataResetService.resetAll()` теперь сбрасывает и выбранные сферы |
| Подключение к приложению | `main.dart`: `NpdShieldApp` читает `FirstRunService` и показывает `OnboardingScreen` или `HomeShell`; очистка возвращает приложение к онбордингу |
| Настройки | `SettingsScreen` (`lib/presentation/settings/settings_screen.dart`): раздел «Управление данными» (демо и очистка); добавлена вкладка «Настройки» в `HomeShell` |

## Рабочий путь

1. При первом запуске `NpdShieldApp` видит, что онбординг не пройден, и
   показывает `OnboardingScreen`.
2. Пользователь выбирает сферы, при желании заполняет профиль ИП и выбирает
   режим старта. При выборе «демо» показывается подтверждение перезаписи.
3. По завершении сохраняются профиль и сферы, вызывается
   `FirstRunService.completeOnboarding`, приложение переходит в `HomeShell`.
4. Во вкладке «Настройки» можно повторно загрузить демо или очистить все
   данные. После очистки `NpdShieldApp` снова показывает онбординг.

## Критерии готовности PRD (модуль 0)

| Критерий | Проверка |
|----------|----------|
| Первый запуск показывает онбординг | `NpdShieldApp` переключает экраны по `FirstRunService` |
| Режимы «с нуля» и «демо» работают | `onboarding_screen_test` (оба режима) |
| Демо загружается только по явному действию | `showDemoDataConfirmation` в онбординге и настройках |
| Очистка возвращает приложение к состоянию после установки | `settings_screen_test`, `data_reset_service_test` |
| Факт завершения онбординга сохраняется между запусками | `first_run_service_test` (фаза 26) |
