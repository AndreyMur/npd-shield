# 🛡️ Своё дело — Мобильное приложение для безопасного ведения бизнеса ИП на НПД

**Product Brief v1.0**

---

## 📌 Краткое описание продукта

**Своё дело** — мобильное приложение для индивидуальных предпринимателей на режиме НПД (самозанятость), которые совмещают несколько видов деятельности (в частности, грузоперевозки и IT-услуги). Приложение решает главную проблему таких предпринимателей — **юридическую безопасность сделок** — через умный конструктор договоров, автоматическую проверку рисков переквалификации в трудовые отношения и интеллектуальное разделение финансовых потоков.

**Ключевое обещание:** «Ваш бизнес под защитой. Каждая сделка — юридически безупречна.»

---

## 🎯 Проблема и целевая аудитория

### Проблема

ИП на НПД с комбинированной деятельностью (ОКВЭД 49.41 + 62.01/62.02/63.12) сталкивается с тремя критическими рисками:

1. **Риск переквалификации договора ГПХ в трудовой** — особенно в сфере грузоперевозок. Последствия: доначисление НДФЛ (13%), страховых взносов (30%), штрафы до 100 000 ₽ за каждый договор.
2. **Риск превышения лимита 2.4 млн руб.** — автоматический переход на общую систему налогообложения с задним числом.
3. **Хаос в учёте** — смешение доходов от разных сфер, сложности с формированием чеков и актов.

### Целевая аудитория

**Первичный сегмент (Early Adopters):**

- ИП на НПД с 2+ видами деятельности
- Годовой доход: 500 000 — 2 400 000 ₽
- Работают с юридическими лицами (B2B)
- Возраст: 25-45 лет
- Технически подкованы, используют смартфон для бизнеса

**Типичный портрет:**

- Дальнобойщик-фрилансер, который параллельно делает сайты на заказ
- IT-разработчик, подрабатывающий курьерской доставкой
- Логист-предприниматель с собственным автопарком до 3 машин

## 💡 Решение: Ключевые фичи

### 🏗️ Модуль 1: Контекстный дашборд с разделением сфер

**Что делает:**

- Главный экран с финансовой сводкой по каждой сфере деятельности отдельно
- Переключатель «Все / IT / Логистика» одним тапом
- Визуализация лимита 2.4 млн с прогнозом исчерпания
- Расчёт налога к уплате с учётом страховых взносов ИП

**Ценность:**
Пользователь видит реальную картину бизнеса, а не свалку цифр. Понимает, какая сфера «съедает» лимит быстрее, и может заранее принять решение.

**Ключевые метрики:**

- Время до понимания финансовой ситуации: < 3 секунды
- Точность прогноза исчерпания лимита: ±15 дней на горизонте 3 месяцев

---

### 📝 Модуль 2: Генератор безопасных договоров

**Что делает:**

- Библиотека из 20+ юридически выверенных шаблонов договоров
- Автоматическая адаптация под ОКВЭД (49.41 или 62.01/62.02)
- Автозаполнение реквизитов из профиля пользователя
- Специфичные поля для каждой сферы:
  - **Логистика:** маршрут, вес груза, характеристики ТС, срок доставки
  - **IT:** описание результата, техтребования, этапы сдачи

**Ценность:**
Договор за 2 минуты вместо 2 часов у юриста. Каждый договор содержит «защитные формулировки», которые доказывают гражданско-правовой характер отношений.

**Ключевые метрики:**

- Время создания договора: < 2 минуты
- Доля договоров с защитными формулировками: 100%

---

### 🛡️ Модуль 3: Risk Shield — юридический щит

**Что делает:**

- Автоматическая проверка каждого сгенерированного договора на риски
- Анализ загруженных извне договоров (от заказчиков)
- Поиск 50+ маркеров риска через RegExp-паттерны
- Визуализация:
  - 🔴 Критический риск — «подчиняется правилам внутреннего распорядка»
  - 🟡 Средний риск — «рабочее время с 9:00 до 18:00»
  - 🟢 Безопасно — «самостоятельно определяет порядок работ»
- **Индекс безопасности** в виде цветовой шкалы (0-100%)
- Предложение безопасных альтернатив для каждого найденного риска

**Ценность:**
Пользователь получает «вторую пару глаз» юриста. Может загрузить договор от заказчика и за 10 секунд понять, стоит ли его подписывать.

**Ключевые метрики:**

- Точность обнаружения рисков: > 90%
- Время анализа договора (30 КБ): < 500 мс
- Ложноположительные срабатывания: < 5%

---

### 🧾 Модуль 4: Умный чек и документооборот

**Что делает:**

- Генерация чека с автоматической привязкой к договору
- Формирование акта выполненных работ
- Deep link на приложение «Мой налог» с предзаполненными данными
- Архив всех документов с поиском по контрагенту, дате, сумме

**Ценность:**
Пользователь никогда не забудет отправить чек заказчику. Все документы в одном месте, готовы к экспорту для налоговой проверки.

**Ключевые метрики:**

- Доля сделок с автоматически сформированным чеком: > 95%
- Время формирования чека: < 10 секунд

---

### 🔔 Модуль 5: Система уведомлений и напоминаний

**Что делает:**

- Push-уведомления о приближении к лимиту 2.4 млн (за 60, 30 дней, при 80%)
- Напоминания о неоплаченных счетах
- Предупреждения о нестандартных транзакциях (аномалии)
- Еженедельный дайджест: «За неделю вы заработали X, заплатили налога Y, до лимита осталось Z»

**Ценность:**
Пользователь никогда не пропустит критическое событие. Проактивная защита от ошибок.

## 🛠️ Техническая реализация на Flutter

### Почему Flutter?

1. **Кроссплатформенность** — один код для iOS и Android. Критично для стартапа с ограниченным бюджетом.
2. **Нативная производительность** — 60 FPS даже на устройствах среднего класса. Дальнобойщики часто используют старые Android-смартфоны.
3. **Offline-first архитектура** — Flutter + Isar DB позволяют работать без интернета. Критично для логистов в дороге.
4. **Material Design 3** — современный UI из коробки, поддержка Dynamic Color на Android 12+.

**2. Risk Shield — анализ текста:**

```dart
class RiskAnalyzerUseCase {
  Future<RiskReport> analyze(String contractText) async {
    final markers = await _riskMarkerRepository.getAll();
    final foundRisks = <RiskMatch>[];

    for (final marker in markers) {
      final regex = RegExp(marker.pattern, caseSensitive: false);
      final matches = regex.allMatches(contractText);

      if (matches.isNotEmpty) {
        foundRisks.add(RiskMatch(
          marker: marker,
          matchedText: matches.map((m) => contractText.substring(m.start, m.end)).toList(),
        ));
      }
    }

    return RiskReport(
      risks: foundRisks,
      safetyIndex: _calculateSafetyIndex(foundRisks, markers.length),
    );
  }
}
```
