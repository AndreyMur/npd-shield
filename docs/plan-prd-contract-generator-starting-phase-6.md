# Plan: Safe Contract Generator

**PRD:** prd-contract-generator (фазы с 6)
**Дата:** 2026-08-31

## Фазы реализации

### Фаза 6: Tracer Bullet — Модель данных и библиотека базовых шаблонов

**Цель:** Рабочий путь «выбор шаблона → заполнение обязательных полей → генерация PDF». Проверка основной гипотезы и базовая архитектура хранения договоров.
**Затрагивает:** frontend (Flutter) / database (Isar)
**Задачи:**
- [x] Создать Isar-коллекции `ContractDraft` (templateId, filledFields, status, createdAt) и `Template` (id, sphere, title, description) с миграциями.
- [x] Добавить базовые шаблоны договоров (2 IT, 2 логистики, 2 универсальных) в Assets приложения, размер каждого ≤ 50 КБ.
- [x] Реализовать экран «Библиотека шаблонов» с карточками (название, описание, категория, сфера).
- [x] Реализовать форму для основных полей договора с базовой валидацией обязательных полей и autofill реквизитов из профиля.
- [x] Написать unit-тесты для репозиториев шаблонов и договоров, widget-тесты для экрана библиотеки и формы.
**Когда готова:** Пользователь выбирает шаблон, заполняет поля, получает черновик договора, сохранённый в Isar; автозаполнение реквизитов работает при наличии данных в профиле; форма доступна для скринридеров.

### Фаза 7: Конструктор договора и генерация PDF

**Цель:** Полноценный пошаговый мастер с предпросмотром и генерацией PDF-файла с кириллицей.
**Затрагивает:** frontend (Flutter)
**Задачи:**
- [x] Реализовать пошаговый мастер заполнения (3-5 шагов) с индикатором прогресса и подсказками для каждого поля.
- [x] Реализовать предпросмотр документа в реальном времени на основе заполненных полей.
- [x] Реализовать генерацию PDF (A4, поля 20 мм, шрифт Roboto 12pt/заголовки 14pt bold, нумерация страниц).
- [x] Реализовать Bottom sheet предпросмотра готового PDF перед сохранением и шаринг через стандартные приложения.
- [x] Написать widget-тесты для мастера заполнения, интеграционные тесты генерации PDF (кириллица, корректный макет, < 2 секунд).
**Когда готова:** Пользователь создаёт договор от выбора шаблона до готового PDF за < 2 минут; PDF корректно отображается в Adobe Reader, Apple Preview, Chrome; генерация PDF < 2 секунд.

### Фаза 8: Защитные формулировки и управление договорами

**Цель:** Гарантированное наличие защитных формулировок в каждом договоре и система управления черновиками/архивом.
**Затрагивает:** frontend (Flutter) / database (Isar)
**Задачи:**
- [x] Внедрить автоматическую вставку стандартных защитных формулировок (ГПХ-характер) во все шаблоны, с визуальной маркировкой значком щита.
- [x] Реализовать статусы договора: Черновик → Подписан → Архив, с переходом между ними.
- [x] Реализовать редактирование черновиков, дублирование существующего договора и поиск по названию, контрагенту, дате.
- [x] Реализовать автосохранение черновика каждые 30 секунд и восстановление незавершённой сессии.
- [x] Написать unit-тесты для логики статусов и автосохранения, widget-тесты для архива и поиска.
**Когда готова:** 100% договоров содержат защитные формулировки (проверено тестами на всех шаблонах); пользователь может сохранять, редактировать, дублировать, архивировать договоры и искать их; черновик восстанавливается после перезапуска приложения.

### Фаза 9: Полная библиотека шаблонов (20+)

**Цель:** Довести библиотеку до 20+ юридически выверенных шаблонов с поиском и фильтрацией для покрытия критерия готовности.
**Затрагивает:** frontend (Flutter)
**Задачи:**
- [x] Расширить библиотеку до 20+ шаблонов: 10 для IT, 10 для логистики, с адаптацией под ОКВЭД (49.41 / 62.01-62.02).
- [x] Добавить категории «Логистика», «IT-услуги», «Универсальные» со сферной маркировкой (IT — синий, Логистика — оранжевый).
- [x] Реализовать поиск и фильтрацию шаблонов по типу деятельности и категории.
- [x] Добавить пометку «Рекомендовано» для наиболее безопасных шаблонов и примеры заполнения в карточках.
- [x] Написать тесты: проверка, что 100% шаблонов содержат защитные формулировки; тесты поиска и фильтрации.
**Когда готова:** В библиотеке 20+ шаблонов (10 IT, 10 логистика), все содержат защитные формулировки (проверено тестом); поиск, фильтрация и пометка «Рекомендовано» работают.

**Цель:** Подтвердить нефункциональные требования и гарантировать соответствие всем критериям готовности модуля.
**Затрагивает:** frontend (Flutter) / database (Isar)
**Задачи:**

- [x] Провести валидацию ввода на безопасность (отсутствие вредоносного кода в шаблонах и вводе) и обеспечить клавиатурную навигацию.

- [ ] Проверить итоговое время создания договора (< 2 минут) и все критерии готовности PRD на реальном устройстве. *(автоматизированная часть подтверждена, ручной чек-лист — в `docs/contract-generator-report.md`)*
- [x] Устранить выявленные узкие места и задокументировать результат.
**Когда готова:** Все критерии готовности PRD выполнены: 20+ шаблонов, время создания < 2 минут, 100% защитных формулировок, PDF корректный, автозаполнение, сохранение/восстановление, accessibility; производительность и надёжность подтверждены тестами.
