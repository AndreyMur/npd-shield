# Отчёт по модулю Business Management Core (Фаза 36)

## Дата: 2026-09-17
## Ветка: feature-phase-36

## Назначение

Интерфейс отчётов, экспорта и резервного копирования (Модуль 5): пользователь
выбирает период, видит сводку, график и разбивку по сферам и клиентам,
выгружает операции и счета в CSV, формирует PDF-отчёт, а также создаёт и
восстанавливает резервные копии всех данных.

## Что реализовано

| Задача | Реализация |
|--------|------------|
| Экран отчётов | `lib/presentation/reports/reports_screen.dart`: период (месяц/квартал/год/произвольный), карточка итогов (доход, расход, прибыль, налог), график, таблицы по сферам и клиентам. Периоды — `lib/presentation/reports/report_period.dart`, селектор — `report_period_selector.dart` |
| График | `lib/presentation/reports/report_sphere_chart.dart`: столбчатая диаграмма дохода и расхода по сферам на `fl_chart` с легендой и всплывающими подсказками |
| Экспорт CSV | Кнопки «Операции в CSV» и «Счета в CSV» используют `CsvExportService`; файл сохраняется на устройство |
| Экспорт PDF | Кнопка «Отчёт в PDF» верстает `ReportPdfService` (Roboto, кириллица) и сохраняет файл |
| Резервное копирование | Карточка «Резервное копирование»: «Создать копию» (`BackupService.exportBackup`) и «Восстановить из копии» (`importBackup`) с подтверждением замены данных |
| Сохранение и выбор файлов | `lib/data/files/export_file_saver.dart` (`ExportFileSaver` + `FilePickerExportFileSaver`), `lib/data/files/backup_file_picker.dart` (`BackupFilePicker` + `FilePickerBackupFilePicker`) |
| Навигация | Раздел «Отчёты» добавлен в `HomeShell` перед настройками; зависимости проброшены из `main.dart` |

## Рабочий путь

1. `ReportsScreen` строит отчёт через `ReportBuilder` за выбранный период и
   показывает итоги, график и разбивку по сферам и клиентам.
2. Период переключается чипами «Месяц / Квартал / Год» или произвольным
   диапазоном дат (`showDateRangePicker`); при смене периода отчёт
   пересчитывается.
3. Выгрузка CSV формирует `CsvExport` из операций периода и счетов по дате
   выставления и сохраняет байты через `ExportFileSaver` (нативный диалог
   сохранения `file_picker`).
4. PDF-отчёт генерируется в фоновом изоляте с кириллическими шрифтами и
   сохраняется тем же сервисом.
5. «Создать копию» вызывает `BackupService.exportBackup()` и сохраняет JSON;
   «Восстановить из копии» выбирает файл, запрашивает подтверждение
   (`showBackupImportConfirmation`) и заменяет данные, после чего отчёт
   пересчитывается.
