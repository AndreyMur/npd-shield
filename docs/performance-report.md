## Дата: 2026-09-02

## Критерии приемки
- ✅ Время загрузки дашборда: < 1 секунды

## Оптимизации

### Реализованные
1. ✅ Кэширование агрегаций (IncomeSummary, AverageMonthlyIncome, IncomeSeries)
2. ✅ Индексы на полях date и sphere
3. ✅ Инвалидация кэша при изменении данных
4. ✅ Шифрование AES-256 с кэшированием ключей

### Рекомендации
1. Использовать `const` конструкторы виджетов где возможно
2. Избегать пересоздания виджетов в build()
3. Использовать RepaintBoundary для сложных графиков
4. Мониторить размер БД и очищать старые данные

## Инструменты профилирования

### Flutter DevTools
```bash
flutter pub global activate devtools
flutter pub global run devtools
```

1. Запустить приложение в режиме профилирования:
   ```bash
   flutter run --profile
   ```

2. Открыть DevTools по ссылке из консоли

3. Вкладка **Performance**:
   - Записать сессию при прокрутке дашборда
   - Проверить FPS и время кадров
   - Искать пропуски кадров (jank)

4. Вкладка **Memory**:
   - Сделать snapshot памяти
   - Проверить утечки
   - Отслеживать аллокации

### Команды для тестирования
```bash
# Запуск с профилированием
flutter run --profile

# Запуск с включенным оверлеем производительности
flutter run --profile --enable-impeller

# Тест производительности
flutter test --profile
```

## Метрики для мониторинга

### Время загрузки
```dart

// ... загрузка данных
stopwatch.stop();

```

### FPS
Отслеживается в Flutter DevTools автоматически.
