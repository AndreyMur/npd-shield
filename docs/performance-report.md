## Инструменты профилирования

### Flutter DevTools
```bash
flutter pub global activate devtools
flutter pub global run devtools
```

1. Запустить приложение в режиме профилирования:
   ```bash
   flutter run --profile
   ```

2. Открыть DevTools по ссылке из консоли

3. Вкладка **Performance**:
   - Записать сессию при прокрутке дашборда
   - Проверить FPS и время кадров
   - Искать пропуски кадров (jank)

4. Вкладка **Memory**:
   - Сделать snapshot памяти
   - Проверить утечки
   - Отслеживать аллокации

### Команды для тестирования
```bash
# Запуск с профилированием
```

### Профилирование p95 построения кадра

Цель PRD: p95 построения кадра < 16 мс при скролле и переключении
разделов. Автоматизированный замер в widget-тесте
(`test/phase36_redesign_test.dart`, группа «Производительность p95
построения кадра»): 24 последовательных кадра на экране «Настройки» при
375 px.

| Метрика | Значение | Бюджет | Статус |
|---------|----------|--------|--------|
| p95 построения кадра | 0.41 мс | < 16 мс | ✅ |
| Максимальный кадр | 1.17 мс | < 16 мс | ✅ |

Замер выполняется в тестовой среде (CPU, без GPU), поэтому даёт нижнюю
оценку; на устройстве среднего класса бюджет также подтверждён
профилированием `flutter run --profile` (DevTools → Performance).

### Оптимизации фазы 36

1. ✅ Разделы `HomeShell` обёрнуты в `RepaintBoundary`: перерисовка при
   переключении не затрагивает соседние экраны.
2. ✅ `IndexedStack` сохраняет состояние разделов — переключение не
   пересоздаёт экраны и не запускает повторную загрузку данных.
3. ✅ Motion-переходы 150–300 мс на `FadeTransition`/`SlideTransition` с
   отключением при reduced-motion.
