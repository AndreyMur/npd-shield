# PRD: Smart Receipt & Document Flow

**Дата**: 2026-08-31
**Статус**: Draft

## Цель

Позволить ИП на НПД автоматически формировать чеки и акты выполненных работ, привязанные к договорам, чтобы пользователь никогда не забывал отправить чек заказчику и имел все документы в одном месте для налоговой проверки.

## Пользовательские сценарии

- Пользователь завершает сделку -> Автоматически формируется чек, привязанный к договору
- Пользователь нажимает «Отправить чек» -> Чек отправляется заказчику через мессенджер/email
- Пользователь формирует акт -> Акт автоматически заполняется данными из договора
- Пользователь ищет документ -> Находит по контрагенту, дате или сумме через поиск
- Пользователь открывает deep link -> Переходит в приложение «Мой налог» с предзаполненными данными

## В скоупе

- Генерация чека с автоматической привязкой к договору
- Формирование акта выполненных работ на основе данных договора
- Deep link на приложение «Мой налог» с предзаполненными данными
- Архив всех документов с поиском по контрагенту, дате, сумме
- Экспорт документов в PDF
- Привязка документов к транзакциям из дашборда

## Не в скоупе

- Автоматическая отправка чеков через API ФНС (v2)
- Интеграция с бухгалтерскими системами (1С, Контур)
- Юридическая сила электронных документов (без ЭЦП)
- Мультиязычные документы

## Технические ограничения

- Deep link на «Мой налог» работает только на мобильных устройствах
- Генерация PDF происходит локально
- Максимальный архив: 1000 документов без деградации производительности
- Формат чека соответствует требованиям ФНС для НПД

## Критерии готовности

- [x] Чек генерируется автоматически при завершении сделки
- [x] Время формирования чека: < 10 секунд
- [ ] Доля сделок с автоматически сформированным чеком: > 95%
- [x] Акт выполненных работ корректно заполняется из данных договора
- [ ] Deep link на «Мой налог» корректно открывает приложение и передаёт данные
- [ ] Архив документов доступен и функционален при 1000+ документах
- [ ] Поиск работает за < 500 мс по базе 1000 документов
- [ ] Accessibility: все элементы доступны для скринридеров

## Функциональные требования

### Генерация чека

- Автоматическое заполнение реквизитов из профиля ИП
- Привязка к договору (номер, дата, сумма)
- Формат чека соответствует требованиям ФНС для НПД
- Поля: наименование услуги, сумма, дата, ИНН покупателя
- Генерация PDF-версии чека для скачивания

### Акт выполненных работ

- Автоматическое заполнение из данных договора
- Поля: описание работ, результат, сумма, дата выполнения
- Подписи сторон (поля для распечатки)
- Привязка к договору и чеку

### Deep link на «Мой налог»

- Формирование URL с параметрами: сумма, тип клиента (юрлицо/физлицо)
- Проверка установки приложения «Мой налог»
- Fallback: копирование данных в буфер обмена
- Инструкция по ручному вводу данных

### Архив документов

- Единый список всех документов (чеки, акты, договоры)
- Группировка по контрагентам
- Сортировка по дате, сумме, типу документа
- Поиск по наименованию контрагента, сумме, дате
- Фильтрация по типу документа и статусу

### Привязка к транзакциям

- Автоматическое сопоставление документов с транзакциями из дашборда
- Визуальная индикация привязки (значок документа рядом с транзакцией)
- Переход к документу из карточки транзакции

## Нефункциональные требования

- **Производительность:** генерация чека за < 10 секунд, поиск за < 500 мс
- **Безопасность:** документы хранятся локально, шифрование AES-256
- **Доступность:** поддержка скринридеров, контрастные режимы
- **Надёжность:** автосохранение при создании документа

## Дизайн и UX

- Карточки документов с иконками по типу (чек, акт, договор)
- Bottom sheet с деталями документа
- Кнопки «Отправить», «Скачать PDF», «Удалить»
- Поиск с автодополнением
- Группировка по контрагентам с аварацией

## Критерии успеха (KPI)

- **Доля автоматических чеков:** > 95% сделок
- **Время формирования:** < 10 секунд
- **Retention rate:** > 65% пользователей используют архив регулярно
- **NPS:** > 45 для модуля документов

## Ограничения и риски

- **Риск:** deep link может не работать при обновлении «Мой налог» -> **Митигация:** fallback с копированием в буфер
- **Риск:** формат чека может измениться -> **Митигация:** обновление через App Store
- **Ограничение:** документы не имеют юридической силы без ЭЦП -> **Митигация:** дисклеймер

## Границы объёма работ

**Входит:**
- Генерация чеков с привязкой к договорам
- Формирование актов выполненных работ
- Deep link на «Мой налог»
- Архив документов с поиском
- Экспорт в PDF
- Привязка к транзакциям

**Исключено:**
- Автоматическая отправка чеков через API ФНС
- Интеграция с бухгалтерскими системами
- Юридическая сила документов
- Мультиязычные документы
