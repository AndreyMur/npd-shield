# PRD: Context Dashboard with Activity Separation

**Дата**: 2026-08-31
**Статус**: Draft

## Цель

Предоставить ИП на НПД мгновенный доступ к финансовой картине по каждой сфере деятельности отдельно, чтобы пользователь понимал, какая сфера «съедает» лимит быстрее, и мог заранее принять решение о распределении доходов.

## Пользовательские сценарии

- Пользователь открывает приложение -> Видит суммарный доход за месяц и прогноз исчерпания лимита 2.4 млн
- Пользователь нажимает «IT» -> Видит только доходы и расходы по IT-проектам
- Пользователь нажимает «Логистика» -> Видит только данные по грузоперевозкам
- Пользователь выбирает «Все» -> Видит объединённую статистику по всем сферам
- Пользователь смотрит на индикатор лимита -> Видит цветовую шкалу и количество дней до исчерпания

## В скоупе

- Главный экран с финансовой сводкой по каждой сфере деятельности
- Переключатель «Все / IT / Логистика» одним тапом
- Визуализация лимита 2.4 млн руб. с прогнозом исчерпания (цветовая шкала)
- Расчёт налога к уплате с учётом страховых взносов ИП
- Графики доходов по месяцам для каждой сферы
- Показатель «до лимита осталось X руб. (Y дней)»

## Не в скоупе

- Интеграция с банками для автоматического импорта выписок (Фаза 2)
- Экспорт данных в Excel/PDF (отдельная фича)
- Облачная синхронизация (Фаза 3)
- Мультивалютность (только рубли)

## Технические ограничения

- Данные хранятся локально в Isar DB (offline-first)
- Прогноз исчерпания лимита основан на среднем доходе за последние 3 месяца
- Визуализация должна работать на устройствах среднего класса (60 FPS)
- Поддержка Android 8.0+ и iOS 14+

## Критерии готовности

- [ ] Дашборд загружается за < 1 секунды
- [ ] Время до понимания финансовой ситуации: < 3 секунды
- [ ] Переключение между сферами работает без задержек (< 100 мс)
- [ ] Прогноз исчерпания лимита точен в пределах ±15 дней на горизонте 3 месяцев
- [ ] Точность расчёта налога: ±1% от расчёта ФНС
- [ ] Дашборд корректно отображает данные при 0 транзакциях
- [ ] Поддержка темновой и светлой темы
- [ ] Accessibility: поддержка скринридеров (TalkBack, VoiceOver)

## Функциональные требования

### Сводка по сферам

- Отображение суммарного дохода за текущий месяц по каждой сфере
- Отображение суммарного дохода за текущий год по каждой сфере
- Показатель «средний доход в месяц» для каждой сферы

### Индикатор лимита

- Визуальная шкала (0-2.4 млн) с текущим значением
- Цветовая кодировка: зелёный (< 70%), жёлтый (70-90%), красный (> 90%)
- Текстовый прогноз: «До лимита осталось X руб. (Y дней при текущем темпе)»

### Графики

- Линейный график доходов по месяцам (последние 12 месяцев)
- Раздельная визуализация по сферам (цветовые линии)
- Возможность выбора периода: неделя / месяц / квартал / год

### Налоговый калькулятор

- Автоматический расчёт налога 6% от дохода
- Вычет страховых взносов ИП (фиксированная часть)
- Отображение суммы к уплате за текущий период

## Нефункциональные требования

- **Производительность:** время загрузки дашборда < 1 секунды, FPS ≥ 60
- **Безопасность:** данные хранятся только локально, шифрование AES-256
- **Доступность:** поддержка скринридеров, контрастные режимы
- **Масштабируемость:** поддержка до 10 000 транзакций без деградации производительности

## Дизайн и UX

- Material Design 3 с Dynamic Color (Android 12+)
- Цвета сфер: IT — синий (#2196F3), Логистика — оранжевый (#FF9800)
- Прогресс-бар лимита с градиентом зелёный-жёлтый-красный
- Карточки сфер с иконками и ключевыми метриками
- Навигация: нижний навбар с табами «Дашборд», «Договоры», «Риски», «Документы»

## Критерии успеха (KPI)

- **Time to value:** < 5 минут до первого взаимодействия с дашбордом
- **Retention rate (7 дней):** > 50% пользователей возвращаются на дашборд
- **NPS:** > 40 для модуля дашборда

## Ограничения и риски

- **Риск:** неточные данные при ручном вводе транзакций -> **Митигация:** валидация ввода, подсказки
- **Риск:** неточность прогноза лимита -> **Митигация:** указание погрешности в интерфейсе
- **Ограничение:** прогноз не учитывает сезонность -> **Митигация:** дисклеймер в UI

## Границы объёма работ

**Входит:**
- Экран дашборда с переключением сфер
- Индикатор лимита с прогнозом
- Графики доходов
- Налоговый калькулятор

**Исключено:**
- Автоимпорт данных из банков
- Экспорт отчётов
- Облачная синхронизация
- Мультивалютность
- Прогнозирование на основе ML
