# PRD: Modern Colorful UI Redesign

**Дата**: 2026-09-17
**Статус**: Draft

## Цель

Обновить визуальный язык NPD Shield до современного яркого fintech-стиля и внедрить единую дизайн-систему, чтобы приложение выглядело премиально, вызывало доверие и снижало когнитивную нагрузку при работе с финансами. Сейчас все экраны используют базовую Material 3-тему с одним seed-цветом без фирменной типографики, градиентов и motion-языка.

## Пользовательские сценарии

- Пользователь открывает приложение -> Видит фирменный градиентный экран и единый визуальный стиль на всех экранах
- Пользователь смотрит дашборд -> Ключевые метрики (доход, лимит, налог) считываются за секунды благодаря акцентной типографике и цветовому кодированию
- Пользователь переключает «Все / IT / Логистика» -> Смена цветового акцента сферы происходит мгновенно и без потери контекста
- Пользователь проверяет договор в Risk Shield -> Уровни риска различаются цветом, иконкой и текстом, а не только цветом
- Пользователь переключает светлую/тёмную тему -> Обе темы сохраняют контраст и фирменный характер
- Пользователь со слабым зрением / включённым reduced-motion -> Интерфейс остаётся читаемым, анимации отключаются

## В скоупе

- Единая дизайн-система: цветовые, типографические, spacing-, radius-, elevation- и motion-токены
- Фирменная палитра (light + dark) и семантические токены: primary, secondary, accent, surface, muted, border, destructive, warning, success
- Система градиентов: брендовый (primary→secondary), доход (success), риск (warning→destructive), лимит (зелёный→жёлтый→красный)
- Цветовое кодирование сфер: IT — синий `#2196F3`, Логистика — оранжевый `#FF9800`, «Все» — фирменный градиент
- Фирменная типографика с поддержкой кириллицы (заголовки/текст — Inter, числовые метрики — моноширинный JetBrains Mono), полная типо-шкала
- Библиотека базовых компонентов: карточки, кнопки, поля ввода, чипы, сегмент-контролы, баннеры статуса, empty/loading/error-состояния
- Редизайн всех 11 разделов навигации: Дашборд, Операции, Клиенты, Счета, Шаблоны, Договоры, Документы, Проверка, Уведомления, Отчёты, Настройки
- Редизайн онбординга и экрана-заглушки загрузки
- Обновление графиков (`fl_chart`) под новые токены: палитра, легенды, tooltips, подписи
- Motion-язык: длительности 150–300 мс, ease-out на вход / ease-in на выход, переходы между экранами, stagger-появление карточек, shimmer-загрузка
- Иконографическая дисциплина: единый стиль и размеры, без эмодзи как структурных иконок
- Адаптив: мобильные breakpoint-ы, наследование системы в desktop-режиме
- Доступность: контраст ≥4.5:1 для текста, поддержка reduced-motion, корректные semantic labels
- Взаимодействие с Dynamic Color: фирменная палитра используется как основа, системные цвета — опциональный слой

## Не в скоупе

- Изменение функциональности, бизнес-логики, навигационной структуры и состава разделов
- Новые продуктовые фичи и экраны
- Редизайн логотипа, создание маскота и иллюстративного стиля
- Изменение генерации PDF-документов (договоры, чеки, акты, отчёты)
- Маркетинговый лендинг и материалы стора
- Полноценная отдельная desktop-плотность данных (таблицы, multi-window)
- Поддержка планшетных двухпанельных раскладок сверх текущего breakpoint 900 px
- Локализация на новые языки

## Технические ограничения

- Flutter + Material 3 (`useMaterial3: true`), тема централизована в `lib/core/theme/app_theme.dart`; недопустимы хардкод-цвета на экранах
- Dynamic Color (`dynamic_color`) уже подключён и должен продолжать работать
- Offline-first: дизайн не должен зависеть от сети и внешних CDN-шрифтов во время выполнения — шрифты подключаются как ассеты
- Текущий шрифт Roboto подключён как asset; переход на новую типографику требует вложения файлов шрифтов с кириллицей
- Производительность: 60 FPS на устройствах среднего класса; градиенты и blur использовать умеренно, избегать тяжёлых эффектов на скролле
- Совместимость: Android 8.0+, iOS 14+; десктоп (Windows) должен продолжать собираться и работать
- Существующий набор widget- и unit-тестов не должен ломаться; изменение текстов/структуры виджетов требует обновления тестов
- Ограничения площадки: размер приложения растёт с числом начертаний шрифта — подключать только используемые веса

## Функциональные требования

### Дизайн-токены

- Определены семантические цветовые токены для light и dark с гарантированным контрастом
- Определена типо-шкала (display, headline, title, body, label, metric) с фиксированными размерами и line-height
- Определена spacing-шкала по ритму 4/8 dp и radius-шкала (карточки, кнопки, поля, чипы)
- Определена motion-шкала (длительности и кривые) с уважением к reduced-motion

### Компоненты

- Карточки: обычная, акцентная (градиентная), метрическая
- Кнопки: primary (градиент), secondary, text, destructive; состояния pressed/disabled/focus
- Поля ввода: label, hint, helper, error; состояния focus/error/disabled
- Чипы и сегмент-контролы с поддержкой цветов сфер
- Статусные баннеры: info, success, warning, danger
- Состояния empty, loading (skeleton/shimmer), error — единообразно на всех экранах

### Экраны

- Все разделы используют общие токены и компоненты; отклонений от системы нет
- Дашборд: метрики выделены акцентной типографикой, лимит — градиентной шкалой, сферы — цветовыми акцентами
- Risk Shield: уровни риска различаются цветом + иконкой + текстом; индекс безопасности визуализирован по новой шкале
- Онбординг: фирменные градиентные акценты, прогресс шагов, единый стиль
- Графики и отчёты используют обновлённую палитру и читаемые легенды/tooltips

### Анимации

- Переходы между экранами и разделами навигации анимированы в диапазоне 150–300 мс
- Появление контента карточек — мягкий stagger; загрузка — shimmer
- Микро-взаимодействия (нажатия, переключения, статусы) имеют отклик 80–150 мс
- При включённом reduced-motion анимации отключаются или сводятся к мгновенному переходу

## Нефункциональные требования

- **Производительность:** стабильные 60 FPS при скролле и переключении разделов на устройствах среднего класса; время построения экрана не ухудшается относительно текущего
- **Доступность:** контраст текста ≥4.5:1 (основной) и ≥3:1 (вторичный) в обеих темах; touch-target ≥48×48 dp; поддержка скринридеров (TalkBack, VoiceOver); цвет не является единственным носителем смысла; поддержка увеличенного системного шрифта без поломки верстки
- **Консистентность:** 0 хардкод-цветов и размеров вне токенов; единый стиль иконок
- **Надёжность:** обе темы проверены независимо; разделители и состояния различимы в обеих темах
- **Сопровождаемость:** изменение брендового цвета в одном месте меняет весь интерфейс
- **Совместимость:** Dynamic Color не ломает фирменные акценты и семантические цвета риска/успеха

## Дизайн и UX

- **Направление:** яркий градиентный fintech — насыщенные, но не кислотные градиенты; акцент на доверие и читаемость данных
- **Палитра (базовая):** primary `#1E40AF`, secondary `#3B82F6`, accent/success `#059669`, warning `#F59E0B`, danger `#DC2626`, surface light `#FFFFFF`, surface dark `#0F172A`
- **Цвета сфер:** IT `#2196F3`, Логистика `#FF9800`; «Все» — фирменный градиент primary→secondary
- **Градиенты:** брендовый (primary→secondary), доход (accent), риск (warning→danger), лимит (success→warning→danger); применять дозированно — на ключевых CTA и метрических карточках, не как фон всего приложения
- **Типографика:** Inter (300–700) для заголовков и текста; JetBrains Mono для числовых метрик и подписей данных; размер основного текста 16 pt, line-height 1.5
- **Формы:** скругления карточек 16–20 dp, кнопок и полей 12–16 dp, чипов — pill
- **Глубина:** мягкие тени и тонкие границы; избегать «тяжёлого» стекломорфизма и сильного blur на скролле
- **Иконки:** Material Symbols, единый стиль (filled для выбранного состояния, outline для невыбранного), размеры-токены
- **Motion:** смысловые, а не декоративные анимации; не более 1–2 акцентных анимаций на экран; spatial continuity при переходах
- **Анти-паттерны (избегать):** эмодзи как иконки, AI-фиолетово-розовые градиенты, разноцветные градиенты на каждом элементе, серый текст на сером фоне, декоративная анимация без смысла, произвольные размеры шрифтов и отступов
- **Используемые skills:** `ui-ux-pro-max` (палитра, типографика, UX-правила, pre-delivery checklist), `material-3` (Material 3 токены и компоненты), `frontend-design` (визуальная целостность и типографика), `flutter-build-responsive-layout` (адаптивность), `design-mobile-apps` (паттерны мобильных экранов)

## Критерии успеха (KPI)

- **Визуальная консистентность:** 100% экранов используют общие токены; 0 хардкод-цветов вне темы
- **Скорость считывания дашборда:** время до понимания ключевых метрик < 3 секунд (остаётся целевым)
- **Производительность:** p95 построения кадра < 16 мс при скролле ключевых экранов на устройстве среднего класса
- **Доступность:** прохождение контраст-проверки WCAG AA для обеих тем; 0 критичных замечаний скринридера на основных сценариях
- **Субъективная оценка:** ≥80% участников тестирования описывают дизайн как «современный» и «понятный»
- **Retention:** отсутствие падения 7-дневного retention относительно текущего baseline

## Ограничения и риски

- **Риск:** градиенты и тени снижают FPS на слабых устройствах -> **Митигация:** ограничить число градиентных поверхностей, не анимировать тяжёлые эффекты, профилировать на среднем устройстве
- **Риск:** Dynamic Color конфликтует с фирменными семантическими цветами (риск/успех) -> **Митигация:** семантические цвета фиксированы и не переопределяются системной палитрой
- **Риск:** рост размера приложения из-за новых шрифтов -> **Митигация:** подключать только используемые веса, использовать variable font при возможности
- **Риск:** массовые правки ломают существующие тесты -> **Митигация:** обновлять тесты вместе с UI, покрыть ключевые виджеты golden-тестами
- **Риск:** снижение контраста в тёмной теме из-за насыщенных цветов -> **Митигация:** отдельная проверка контраста для dark-токенов, не переносить значения из light
- **Ограничение:** тема централизована в одном файле; крупный редизайн требует его декомпозиции без изменения публичного API `AppTheme`
- **Предположение:** функциональность и навигация не меняются, поэтому редизайн можно вести экран за экраном

- Дизайн-токены (цвет, типографика, spacing, radius, elevation, motion)
- Фирменная палитра и градиентная система для light и dark
- Библиотека базовых компонентов и состояний
- Редизайн всех 11 разделов, онбординга и экрана загрузки
- Обновление графиков и motion-языка
- Адаптивность и доступность в рамках текущей навигационной структуры

**Исключено:**

- Новая функциональность и бизнес-логика
- Логотип, маскот, иллюстрации
- PDF-документы и печатные формы
- Маркетинговый сайт и материалы стора
- Отдельные desktop-раскладки сверх breakpoint 900 px
- Новые языки и локализация
