# PRD: Risk Shield — Юридический Щит

**Дата**: 2026-08-31
**Статус**: Draft

## Цель

Предоставить ИП на НПД «вторую пару глаз» юриста для автоматической проверки договоров на риски переквалификации в трудовые отношения, чтобы пользователь мог за 10 секунд понять, стоит ли подписывать договор от заказчика.

## Пользовательские сценарии

- Пользователь загружает договор от заказчика -> Приложение анализирует текст и показывает найденные риски
- Пользователь создаёт договор через генератор -> Автоматически запускается проверка на риски
- Пользователь видит критический риск -> Получает предложение безопасной альтернативы
- Пользователь смотрит индекс безопасности -> Видит цветовую шкалу от 0% до 100%

## В скоупе

- Автоматическая проверка каждого сгенерированного договора на риски
- Анализ загруженных извне договоров (от заказчиков) в формате TXT
- Поиск 50+ маркеров риска через RegExp-паттерны
- Визуализация рисков:
  - 🔴 Критический риск (красный)
  - 🟡 Средний риск (жёлтый)
  - 🟢 Безопасно (зелёный)
- Индекс безопасности в виде цветовой шкалы (0-100%)
- Предложение безопасных альтернатив для каждого найденного риска
- Сохранение результатов проверки в истории

## Не в скоупе

- Юридическая консультация по результатам проверки
- Автоматическое исправление договоров (только предложение)
- Проверка договоров на казахском/белорусском языках
- Интеграция с юридическими сервисами
- AI-анализ сверх RegExp-паттернов

## Технические ограничения

- Анализ текста происходит локально без серверной обработки
- Максимальный размер анализируемого файла: 100 КБ
- RegExp-паттерны обновляются через App Store (не в реальном времени)
- Время анализа файла 30 КБ: < 500 мс

## Критерии готовности

- [x] База содержит минимум 50 маркеров риска
- [x] Точность обнаружения рисков: > 90% (на тестовой базе договоров)
- [x] Время анализа договора (30 КБ): < 500 мс
- [x] Ложноположительные срабатывания: < 5%
- [x] Индекс безопасности корректно рассчитывается для всех сценариев
- [x] Альтернативы предлагаются для 100% найденных рисков
- [x] История проверок сохраняется и доступна для просмотра
- [x] Accessibility: все элементы доступны для скринридеров

## Функциональные требования

### Маркеры риска

- Категории маркеров:
  - **Критические (красный):** прямые указания на трудовые отношения
  - **Средние (жёлтый):** косвенные признаки подчинённости
  - **Низкие (зелёный):** допустимые формулировки
- Каждый маркер содержит:
  - RegExp-паттерн для поиска
  - Описание риска
  - Пример небезопасной формулировки
  - Безопасную альтернативу

### Анализ договора

- Загрузка TXT-файла из файловой системы
- Автоматический запуск анализа при загрузке
- Параллельный поиск по всем маркерам
- Группировка результатов по уровням риска

### Визуализация результатов

- Индекс безопасности: числовое значение (0-100%) с цветовой шкалой
- Список найденных рисков с фильтрацией по уровню
- Каждый риск раскрывается: описание, где найдено, альтернатива
- Кнопка «Скопировать безопасную формулировку»

### История проверок

- Список всех проверенных договоров
- Дата проверки, индекс безопасности, количество рисков
- Повторный доступ к результатам проверки
- Удаление из истории

### Интеграция с генератором договоров

- Автоматический запуск проверки после создания договора
- Отображение результатов в карточке договора
- Предложение исправлений перед сохранением

## Нефункциональные требования

- **Производительность:** анализ 30 КБ за < 500 мс
- **Безопасность:** файлы не покидают устройство, шифрование локальной БД
- **Доступность:** цвета не являются единственным способом передачи информации (текстовые метки)
- **Надёжность:** корректная работа при отсутствии интернета

## Дизайн и UX

- Индекс безопасности: круговая диаграмма с процентом
- Карточки рисков: цветная полоса слева (красный/жёлтый/зелёный)
- Раскрывающиеся секции для описания и альтернатив
- Кнопка «Скопировать» для безопасных формулировок
- Bottom sheet с итогами проверки

## Критерии успеха (KPI)

- **Точность обнаружения:** > 90% на тестовой базе
- **Ложноположительные:** < 5%
- **Время анализа:** < 500 мс для файлов до 30 КБ
- **Retention rate:** > 70% пользователей используют Risk Shield регулярно
- **NPS:** > 55 для модуля Risk Shield

## Ограничения и риски

- **Риск:** RegExp-паттерны могут давать ложные срабатывания -> **Митигация:** тестовая база, регулярное обновление паттернов
- **Риск:** пользователь может полагаться только на Risk Shield -> **Митигация:** дисклеймер о необходимости юридической консультации
- **Ограничение:** анализ только TXT-файлов (не PDF/DOCX) -> **Митигация:** инструкция по конвертации

## Границы объёма работ

**Входит:**
- 50+ маркеров риска с RegExp-паттернами
- Анализ TXT-файлов до 100 КБ
- Индекс безопасности (0-100%)
- Безопасные альтернативы для каждого риска
- История проверок
- Интеграция с генератором договоров

**Исключено:**
- Юридические консультации
- Автоматическое исправление договоров
- Мультиязычный анализ
- AI beyond RegExp
- Интеграция с юридическими сервисами
