# Отчёт по модулю Smart Receipt (Фаза 18)

## Дата: 2026-09-14
## Ветка: feature-phase-18

## Назначение

Переход из приложения в «Мой налог» с предзаполненными данными чека:
формирование deep link, проверка установки приложения, открытие во внешнем
приложении и fallback с копированием данных в буфер обмена и инструкцией по
ручному вводу.

## Что реализовано

| Задача | Реализация |
|--------|------------|
| Формирование deep link URL | `MyTaxDeepLink` + `ClientType` (`lib/domain/documents/my_tax_deep_link.dart`): URL `https://mynalog.ru/issue` с параметрами суммы, покупателя, ИНН и вида дохода (`income_from_organization` / `income_from_individual`). Тип покупателя определяется по ИНН (10 знаков — юрлицо, иначе физлицо) |
| Проверка установки и открытие | `ExternalAppLauncher` + `UrlLauncherExternalAppLauncher` (`lib/data/deep_link/external_app_launcher.dart`): `canLaunchUrl` и `launchUrl(LaunchMode.externalApplication)` |
| Fallback в буфер обмена | `ClipboardWriter` + `SystemClipboardWriter` (`lib/data/deep_link/clipboard_writer.dart`) и `MyTaxDeepLinkService` (`lib/domain/documents/my_tax_deep_link_service.dart`): при отсутствии приложения или неудачном запуске данные расчёта копируются в буфер обмена |
| Экран deep link | `MyTaxDeepLinkScreen` (`lib/presentation/documents/my_tax_deep_link_screen.dart`): сводка расчёта, выбор типа покупателя, кнопки «Открыть «Мой налог»» и «Скопировать данные», уведомление о fallback |
| Инструкция ручного ввода | Блок «Как ввести данные вручную» с пошаговыми действиями (`MyTaxDeepLink.manualSteps`), суммы и реквизитов |
| Интеграция | Кнопка «Отправить в «Мой налог»» в `DealCompletionScreen`: передаёт в deep link текущие данные чека (сумма, покупатель, ИНН, услуга) |

## Рабочий путь

1. На экране завершения сделки пользователь нажимает «Отправить в «Мой налог»».
2. `MyTaxDeepLinkScreen` показывает данные расчёта и позволяет уточнить тип
   покупателя (юрлицо/физлицо).
3. По кнопке «Открыть «Мой налог»» проверяется установка приложения и
   открывается deep link во внешнем приложении.
4. Если приложение не установлено или запуск не удался, данные копируются в
   буфер обмена, показывается уведомление и инструкция по ручному вводу.

## Критерии готовности PRD

| Критерий | Проверка |
|----------|----------|
| Deep link формирует URL с суммой и типом клиента | `my_tax_deep_link_test` |
| Проверка установки и открытие приложения | `my_tax_deep_link_test`, `my_tax_deep_link_screen_test` |
| Fallback с копированием в буфер обмена | `my_tax_deep_link_test`, `my_tax_deep_link_screen_test` |
| Инструкция по ручному вводу | `my_tax_deep_link_screen_test` |
| Deep link корректно открывает приложение и передаёт данные | `deal_completion_screen_test` (интеграция), ручная проверка на устройстве |

Остальные критерии PRD относятся к последующим фазам: архив с поиском (19),
привязка к транзакциям и финализация (20).

## Ручная проверка на реальном устройстве

1. Завершить сделку и нажать «Отправить в «Мой налог»».
2. Убедиться, что открывается приложение «Мой налог» с переданной суммой и
   типом покупателя.
3. Удалить приложение «Мой налог» и повторить: данные должны скопироваться в
   буфер обмена, а на экране появиться инструкция по ручному вводу.
