# PRD: Notification & Reminder System

**Дата**: 2026-08-31
**Статус**: Draft

## Цель

Обеспечить ИП на НПД проактивную защиту от критических событий через push-уведомления и напоминания, чтобы пользователь никогда не пропускал приближение к лимиту, неоплаченные счета или нестандартные транзакции.

## Пользовательские сценарии

- Пользователь приближается к лимиту 2.4 млн -> Получает push-уведомление за 60, 30 дней и при 80%
- Пользователь не оплатил счёт -> Получает напоминание через 3, 7, 14 дней
- Пользователь совершает нестандартную транзакцию -> Получает предупреждение об аномалии
- Пользователь открывает еженедельный дайджест -> Видит сводку: доход, налог, остаток до лимита

## В скоупе

- Push-уведомления о приближении к лимиту 2.4 млн (за 60, 30 дней, при 80%)
- Напоминания о неоплаченных счетах (3, 7, 14 дней)
- Предупреждения о нестандартных транзакциях (аномалии)
- Еженедельный дайджест: «За неделю вы заработали X, заплатили налога Y, до лимита осталось Z»
- Настройка частоты и типа уведомлений
- Центр уведомлений с историей

## Не в скоупе

- SMS-уведомления
- Email-уведомления
- Интеграция с мессенджерами (Telegram, WhatsApp)
- AI-анализ поведения для персонализации уведомлений
- Геолокационные уведомления

## Технические ограничения

- Push-уведомления работают через Firebase Cloud Messaging (FCM) для Android и APNs для iOS
- Локальные уведомления через flutter_local_notifications
- Фоновые задачи через workmanager для проверки условий
- Доставка уведомлений зависит от настроек устройства

## Критерии готовности

- [ ] Push-уведомления о лимите доставляются за 60, 30 дней и при 80%
- [ ] Напоминания о неоплаченных счетах отправляются через 3, 7, 14 дней
- [ ] Аномалии определяются и уведомляются в реальном времени
- [ ] Еженедельный дайджест формируется и отправляется по расписанию
- [ ] Настройки уведомлений сохраняются и применяются
- [ ] Центр уведомлений показывает историю за последние 30 дней
- [ ] Уведомления не отправляются в ночное время (22:00 - 08:00) по настройке
- [ ] Accessibility: уведомления доступны для скринридеров

## Функциональные требования

### Уведомления о лимите

- Мониторинг текущего дохода относительно лимита 2.4 млн
- Уведомления при достижении порогов: 80%, 90%, 95%, 100%
- За 60 дней до прогнозируемого исчерпания
- За 30 дней до прогнозируемого исчерпания
- Текст уведомления: «До лимита осталось X руб. (Y дней)»

### Напоминания о счетах

- Отслеживание статуса оплаты счетов (оплачен/неоплачен)
- Напоминания через 3, 7, 14 дней после выставления счёта
- Напоминание о просроченном платеже
- Кнопка «Отметить как оплаченный» в уведомлении

### Предупреждения об аномалиях

- Определение нестандартных транзакций:
  - Сумма превышает среднюю в 3+ раза
  - Новый контрагент с крупной суммой
  - Транзакция в необычное время
- Уведомление с описанием аномалии и建議 по проверке

### Еженедельный дайджест

- Формирование каждое воскресенье в 10:00
- Содержание: доход за неделю, налог, остаток до лимита, количество сделок
- Кнопки: «Подробнее», «Сформировать отчёт»
- Отправка через push-уведомление сrich-контентом

### Настройки уведомлений

- Включение/выключение каждого типа уведомлений
- Настройка времени «Тихий режим» (ночное время)
- Выбор порогов для уведомлений о лимите
- Частота напоминаний о счетах

### Центр уведомлений

- Список всех полученных уведомлений
- Группировка по типам
- Фильтрация по дате и типу
- Пометка «прочитано/непрочитано»
- Удаление уведомлений

## Нефункциональные требования

- **Производительность:** уведомления отправляются в течение 1 минуты после наступления условия
- **Безопасность:** уведомления не содержат конфиденциальных данных (суммы, реквизиты)
- **Доступность:** уведомления имеют текстовые метки для скринридеров
- **Надёжность:** уведомления доставляются даже при кратковременной потере сети

## Дизайн и UX

- Центр уведомлений: список с иконками по типам
- Карточка уведомления: заголовок, текст, время, кнопки действий
- Rich push для еженедельного дайджеста (график, цифры)
- Настройки: переключатели с описаниями
- Badge на иконке приложения при непрочитанных уведомлениях

## Критерии успеха (KPI)

- **Доставка уведомлений:** > 95% уведомлений доставляется
- **Retention rate:** > 60% пользователей включают уведомления
- **Вовлечённость:** > 40% пользователей открывают еженедельный дайджест
- **NPS:** > 40 для модуля уведомлений

## Ограничения и риски

- **Риск:** пользователь отключает уведомления -> **Митигация:** мягкое напоминание о важности уведомлений
- **Риск:** уведомления могут раздражать -> **Митигация:** настройка частоты, тихий режим
- **Ограничение:** доставка зависит от настроек устройства -> **Митигация:** инструкция по настройке

## Границы объёма работ

**Входит:**
- Push-уведомления о лимите (60, 30 дней, 80%)
- Напоминания о неоплаченных счетах (3, 7, 14 дней)
- Предупреждения об аномалиях
- Еженедельный дайджест
- Настройки уведомлений
- Центр уведомлений

**Исключено:**
- SMS и email-уведомления
- Интеграция с мессенджерами
- AI-персонализация
- Геолокационные уведомления
